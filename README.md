The portfolio was designed and developed as a responsive, interactive website to present selected professional, academic, and technical projects in one place.

## Featured Projects

### Distribution Analytics Data Warehouse & BI Reporting

A data analytics and business intelligence project based on an AdventureWorks ERP simulation.

**Technologies:**

- Python
- SQL
- Power BI
- DAX
- Dimensional Modeling
- Data Warehousing
- Pandas

### Financial Fraud Detection & Risk Analysis

A transaction-focused analytics project involving data preparation, feature engineering, dimensional modeling, and interactive Power BI reporting.

**Technologies:**

- Python
- SQL
- Power BI
- DAX
- Dimensional Modeling
- Data Analysis
- Pandas

### Hybrid Semantic Text Similarity Model

An undergraduate thesis project proposing a weighted ensemble approach for Semantic Textual Similarity using lexical, static semantic, and contextual text representations.

The model combines:

- Weighted TF-IDF
- GloVe Embeddings
- DeBERTa-v3-base
- Cosine Similarity
- Ridge Regression
- scikit-learn

### AutoTax AI

An Intelligent Systems project exploring AI-assisted tax form processing through conversational assistance, document classification, structured data extraction, and automated BIR Form 2316 completion.

**Technologies:**

- Python
- Generative AI
- OpenRouter API
- JavaScript
- HTML
- CSS
- PDF Generation
- Form Automation
